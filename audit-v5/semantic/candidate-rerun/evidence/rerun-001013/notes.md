# 重驗筆記 — 台光電 / 2383:material_named_relationship:fee79a79f19e5cdf

原始 claim：[[AWS]] (Trainium 2/3 M8 獨家供應)

## 原子主張

1. `SUPPORTED` — AWS Trainium 2 uses M8-grade copper-clad laminate (CCL).
   期間：Trainium 2/2.5 platform; reported July 7, 2025. Exact supply period not specified.
   說明：A KGI industry report identifies M8 CCL for AWS Trainium 2/2.5 compute trays. The product scope is CCL material for that platform; the report does not establish a unit or revenue denominator.
   來源：[2025–26 年 ASIC 伺服器市場成長為亮點 (KGI Taiwan electronic hardware report)](https://www.kgi.com.hk/zh-cn/-/media/files/kgishk/research-reports/tw-reports/it-hardware-07072025e.pdf)；定位：Table 19 and accompanying industry-survey text
2. `SUPPORTED` — 台光電 is the exclusive M8 CCL supplier for AWS Trainium 2.
   期間：Trainium 2; reported July 18, 2025. Exact supply period not specified.
   說明：A media report attributing the claim to market analysts says 台光電 exclusively supplies the M8 CCL used by Trainium 2. This supports the claim secondarily, not through an issuer or AWS disclosure. The exclusivity denominator is not independently quantified.
   來源：[台光電衝上千元俱樂部　法人上修下半年營收展望](https://www.knews.com.tw/news/E370AF1D685F3C4A230254CA12301E85)；定位：Paragraph beginning “法人指出，台光電AI伺服器客戶均為一線大廠”
3. `SUPPORTED` — AWS Trainium 3 uses M8-grade CCL.
   期間：Trainium 3; reported February 2, 2026. Exact supply period not specified.
   說明：A Fubon report describes M8 CCL for Trainium 3 compute trays and its added switch board. This establishes material grade in the reported design, not exclusivity.
   來源：[富邦-AWS Trainium 3 伺服器展望-20260202](https://www.scribd.com/document/1013677185/%E5%AF%8C%E9%82%A6-AWS-Trainium-3-%E4%BC%BA%E6%9C%8D%E5%99%A8%E5%B1%95%E6%9C%9B-20260202)；定位：Section “新增 Switch Board，預期 CCL 台光電、台燿及 PCB 金像電將受益”
4. `CONTRADICTED` — 台光電 is the exclusive M8 CCL supplier for AWS Trainium 3.
   期間：Trainium 3; report dated February 2, 2026.
   說明：The Fubon report names both 台光電 and 台燿 as CCL suppliers for Trainium 3's M8 compute tray. It separately calls 台光電 a main supplier for the added M8 switch board. The report therefore contradicts platform-wide exclusivity; it does not establish the exact allocation share for each supplier.
   來源：[富邦-AWS Trainium 3 伺服器展望-20260202](https://www.scribd.com/document/1013677185/%E5%AF%8C%E9%82%A6-AWS-Trainium-3-%E4%BC%BA%E6%9C%8D%E5%99%A8%E5%B1%95%E6%9C%9B-20260202)；定位：Section “新增 Switch Board，預期 CCL 台光電、台燿及 PCB 金像電將受益”

## 判定

Overall `PARTIAL`。

建議改寫：Secondary reporting supports 台光電 as the exclusive M8 CCL supplier for AWS Trainium 2. For Trainium 3, M8 CCL is reported, but a February 2, 2026 Fubon report names both 台光電 and 台燿 as compute-tray suppliers, so platform-wide exclusivity is not supported.

來源限制：
- No issuer or AWS primary disclosure confirming the named supplier, M8 grade, or exclusivity was located.
- The Trainium 2 exclusivity report attributes the information to market analysts; it does not disclose a measured supplier-share denominator.
- The Trainium 3 evidence is a broker report hosted on Scribd; it distinguishes compute tray from switch board, and does not provide supplier allocation percentages.

Stopped after four focused search turns: secondary evidence supports the Trainium 2 atoms and contradicts Trainium 3 exclusivity. Primary-source confirmation remains unavailable.
