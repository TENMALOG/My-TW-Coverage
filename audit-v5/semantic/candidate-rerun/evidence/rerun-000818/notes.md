# 重驗筆記 — 伯鑫 / 6904:objective_ranking_or_market_share:c9e2cfd9b443469d

原始 claim：伯鑫工具 (6904，Proxene Tools) 總部位於台灣台中神岡，為全球最大工業級活動扳手 (Adjustable Wrench) 製造商，全球市佔率約 25%。

   說明：Issuer report identifies 伯鑫工具股份有限公司, stock code 6904, and lists its head-office address in 神岡區, 台中市.

## 判定

Overall `PARTIAL`。

建議改寫：伯鑫工具股份有限公司（6904；Proxene Tools）的總公司位於台灣台中市神岡區。公司披露其近年全球工業級活動扳手市佔率約25%，但未公開計算口徑；現有資料不足以確認其為全球最大製造商。

來源限制：
- 2024年永續報告書由公司編製，報告載明尚未經外部查證。
- 約25%是公司披露的估計；公開資料未界定市佔率是按銷量、銷售額或其他口徑計算，也未提供計算用分子、分母。
- 官方市府報導中的「全球前三大」不能確認全球第一名，也不足以排除第一名。

已核對 issuer 2024 永續報告及台中市政府報導；全球第一名排序仍無明確證據，依規則列為 UNKNOWN。
