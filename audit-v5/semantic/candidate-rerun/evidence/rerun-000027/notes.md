# 重驗筆記 — 東陽北美AM通路與保險認證件

## 原始主張

> 北美 AM 通路以[[LKQ]]及[[Keystone Automotive]]為最大經銷夥伴，間接受惠[[State Farm]]等保險公司擴大採用 AM 認證件。

## 查證結果

- 東陽2025年年報稱公司在美國市場的塑膠與鈑金產品獲得CAPA產品認證，並取得LKQ Keys IQ認證；年報也稱LKQ為美國最大AM零件通路商。CAPA官方參與者名冊列Tong Yang Industry。認證與通路資格不等於最大客戶或訂單額。
- LKQ官方資料稱Keystone Automotive Industries, Inc.為LKQ子公司，並稱之為美國最大AM汽車零件供應商。因此LKQ與Keystone不是兩個獨立的企業集團。
- 2005年美國聯邦法院裁定背景記載，Tong Yang當時在台灣製造替換件並經包括Keystone在內的經銷商銷售。這證明歷史上的經銷渠道，不能推論2026年Keystone仍為最大買家。
- 東陽2025年年報主要銷貨客戶表以代號A列出一筆2025年占銷貨20.62%的主要客戶，並註明契約可能要求匿名。公開資料無法確定代號A是LKQ／Keystone或其他公司，也沒有披露最大的AM通路伙伴排序。
- State Farm現行官方頁面說，理賠估價可包含非OEM碰撞件，列入其估價的非OEM件須符合CAPA或NSF標準；車主保留實際使用選擇。此頁支持其認證零件估價政策，沒有點名東陽或其零件。
- 東陽年報把State Farm相關措施描述為台灣AM產業市場機會，但未提供東陽獲得State Farm訂單、營收、出貨量或保險理賠份額，不能據此確定東陽直接受益。

## Atomic assessment

1. LKQ及Keystone為東陽現行最大通路客戶：`UNKNOWN`。
2. Keystone是LKQ子公司及美國大型AM供應商：`SUPPORTED`。
3. 東陽2005年曾透過包括Keystone在內的經銷商銷售：`SUPPORTED`，但僅限歷史關係。
4. 東陽年報披露CAPA與LKQ Keys IQ認證：`SUPPORTED`。
5. State Farm現行理賠估價可包含CAPA／NSF認證的非OEM碰撞件：`SUPPORTED`。
6. State Farm的採用直接增加東陽營收或訂單：`UNKNOWN`。
7. 東陽2025年年報主要客戶表列代號A占銷售20.62%，未揭露名稱：`SUPPORTED`。

## 重驗結果

Overall `PARTIAL`。

建議改寫：

> 東陽2025年年報稱，其美國市場產品取得CAPA認證，並取得LKQ的Keys IQ認證；年報亦稱LKQ為美國最大AM零件通路商。LKQ官方資料稱Keystone Automotive Industries是LKQ子公司及美國最大AM零件供應商。2005年美國聯邦法院文件記載，東陽當時曾透過Keystone等經銷商銷售替換件。State Farm現行政策允許其理賠估價列入符合CAPA或NSF標準的非OEM碰撞件，實際使用由車主決定。東陽2025年報將一名占銷貨20.62%的主要客戶以代號A揭露，未能確認該客戶為LKQ／Keystone；也沒有資料量化State Farm政策對東陽營收的直接貢獻。

這是候選重驗結果，不是最終`ACCEPTED`；原公司報告與作者／複核帳本未變更。
