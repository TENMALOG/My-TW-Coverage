# 重驗筆記 — 緯創 / 3231:material_named_relationship:1d9cf38dc03b36db

原始 claim：[[NVIDIA]] — DGX 系統 GPU 基板獨家供應

## 原子主張

1. `SUPPORTED` — 緯創曾供應 NVIDIA DGX 系統相關 GPU 基板。
   期間：2023年至2024年；公開報導未完整界定適用機型或供應期間
   說明：2023年報導將緯創列為 DGX/HGX GPU 基板供應商；緯創於2024年官方表示正增加 NVIDIA DGX 系統供貨。官方聲明確認 DGX 系統供應關係，但未明確確認基板供應。此處將「GPU 基板」理解為 AI 伺服器 GPU baseboard，而非半導體封裝 substrate。
   來源：[台媒：英伟达部分AI服务器订单从纬创转至工业富联](https://www.thepaper.cn/newsDetail_forward_24095457)；定位：第41行
   來源：[Wistron Uses NVIDIA Omniverse and NVIDIA Modulus to Build Digital Twin Platform, Transforming Factory Planning and Operations](https://www.wistron.com/en/Newsroom/2024-03-19-1)；定位：第10–12行
2. `CONTRADICTED` — 在2023年至2024年報導所述期間，緯創是 NVIDIA DGX GPU 基板的唯一供應商。
   期間：截至2024-01-03報導所述的2023年供應情況
   說明：中央社報導引述工業富聯主管稱，工業富聯已有 NVIDIA DGX AI 伺服器晶片基板訂單；這與「DGX 基板只有緯創供應」的廣義獨家說法不相符。公開資料未細分 DGX 機型、板卡版本或特定 SKU，故不能據此判斷是否曾有更窄範圍的獨家安排。
   來源：[工業富聯：供輝達AI伺服器晶片基板逾5成](https://www.cna.com.tw/news/afe/202401030066.aspx)；定位：第290–296行
3. `UNKNOWN` — 緯創截至2026-10-07仍是 NVIDIA DGX GPU 基板的唯一供應商。
   期間：截至2026-10-07；原始 claim 未標明期間
   說明：查得的官方披露確認緯創供應 DGX 系統，但未確認現行 GPU 基板供應商名單或獨家地位。較早資料中另有其他供應商取得 DGX 基板訂單的報導；不足以據此判定2026年的供應狀態。

## 判定

Overall `PARTIAL`。

建議改寫：公開資料支持緯創曾供應 NVIDIA DGX 系統及相關 GPU 基板；但資料亦顯示其他供應商曾取得 DGX 基板訂單，且未能核實緯創目前具有獨家供應地位。

來源限制：
- 緯創官方聲明確認 DGX 系統供應關係，沒有確認 GPU 基板的具體供應範圍或獨家性。
- 獨家性反證來自媒體對供應鏈及工業富聯主管說法的報導；公開資料未細分 DGX 世代、板卡版本或 SKU。
- 原始 claim 未提供期間；不得將2023至2024年的供應鏈報導外推為2026年現況。

已完成針對官方披露及供應鏈報導的聚焦查核。可核實歷史供應關係，但現行、SKU層級的獨家供應狀態仍缺乏可靠公開證據，故該範圍保留 UNKNOWN。
