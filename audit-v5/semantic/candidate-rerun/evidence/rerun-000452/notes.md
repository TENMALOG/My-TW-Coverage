# 重驗筆記 — 第一保 / 2852:objective_ranking_or_market_share:a9cea9f32089f2c8

原始 claim：銷售通路方面，與[[第一銀行]]維持長期銀行保險通路合作關係，並透過車商保代及保險經紀人拓展業務。

## 原子主張

1. `SUPPORTED` — 第一保有透過第一銀行銷售保險商品的通路合作。
   說明：第一保官方網站將「第一銀行－一保安心Plus個人傷害保險專案」列於「行銷通路專案商品保單條款樣張」，支持存在第一銀行相關通路商品合作；該資料本身不證明合作期間長短或業務規模。
   來源：[商品審閱專區－第一產物保險股份有限公司](https://www.firstins.com.tw/service/section/product-review)；定位：「行銷通路專案商品保單條款樣張」表列「華泰保經-新全日守護個人傷害保險專案」
2. `UNKNOWN` — 第一保與第一銀行的銀行保險通路合作關係維持長期。
   說明：找到具名第一銀行通路商品專案，但資料未提供合作起始日期、持續年限或足以確認「長期」的期間證據。
   來源：[商品審閱專區－第一產物保險股份有限公司](https://www.firstins.com.tw/service/section/product-review)；定位：「行銷通路專案商品保單條款樣張」表列「華泰保經-新全日守護個人傷害保險專案」
3. `UNKNOWN` — 第一保透過車商保險代理通路拓展業務。
   說明：檢索到的車商保代資料是產業或監理層面的通用資訊，未能確認第一保本身使用此通路或以此拓展業務；不能以產業通路慣例替代公司特定證據。
4. `UNKNOWN` — 第一保透過保險經紀人通路拓展業務。
   說明：官方商品頁列有「華泰保經」通路專案，支持存在經紀人相關商品專案；但沒有證明該通路被用於拓展業務，或顯示業務因而擴大。
   來源：[商品審閱專區－第一產物保險股份有限公司](https://www.firstins.com.tw/service/section/product-review)；定位：「行銷通路專案商品保單條款樣張」表列「華泰保經-新全日守護個人傷害保險專案」

## 判定

Overall `PARTIAL`。

建議改寫：第一保官方網站列有第一銀行及華泰保經相關的行銷通路商品專案；現有證據未確認與第一銀行合作的長期性、車商保代通路的使用，或透過這些通路拓展業務。

來源限制：
- 官方商品頁列示通路專案可支持具名商品與通路的關聯，但不單獨證明合作期間、銷售規模、通路增長或拓展業務的策略意圖。
- 年報 PDF 的網頁擷取未能取得正文，未據此推定年報內容。
- 未找到足以確認第一保車商保代通路使用情形的公司特定可靠證據；未找到不等於證明沒有使用。

已進行多輪聚焦檢索並查閱第一保官方商品頁；因工具呼叫迭代上限停止，長期性、車商保代及業務拓展目的仍待可直接確認的公司披露。
