# 重驗筆記 — 達方 / 8163:objective_ranking_or_market_share:d28f7bc2f49da606

原始 claim：**達方** (全球最大筆電鍵盤模組製造)

## 原子主張

1. `SUPPORTED` — 達方製造筆電鍵盤模組。
   期間：產品線資料見於2022-12-01公司簡介及2025年第4季法說會；現行產品線期間未另標示。
   說明：達方公司簡介列出筆電鍵盤，2022年公司簡介另列出「Backlit Notebook Keyboard Module」。產品類別有直接支持；來源未提供產量或其他數量單位。
   來源：[達方電子股份有限公司2025年第4季法人說明會](https://www.darfon.com/Content/Upload/files/2026-03-04%20Darfon%202025Q4%20Results%20Conference%20CN(%E4%B8%AD%E6%96%87).pdf)；定位：「產品組合」頁，IT週邊產品定義
   來源：[達方電子公司簡介](https://files.me.ncku.edu.tw/webfile/webdate/file_20221202083308.pdf)；定位：「Human Interface Device Product Lines」頁
2. `SUPPORTED` — 達方是全球最大的筆電鍵盤模組製造商。
   期間：達方官網未標示該排名說法的發布日期；頁面以現在式稱其目前為全球第一。
   說明：達方英文官網明確自述為「the No.1 laptop keyboard manufacturer in the world」，與全球第一大筆電鍵盤製造商的排名主張相符。官網未交代排名基準、比較對象、分母或採用的單位；此為公司自述，尚無獨立排名資料驗證其口徑。2024年媒體報導稱達方當時位居全球前三，這並不排除其為第一，但不足以獨立確認第一名。
   來源：[ABOUT DARFON](https://www.darfon.com/en/about)；定位：公司簡介中 Human Interface Devices 段落
   來源：[DARFON](https://www.darfon.com/en)；定位：首頁標語
   來源：[【頭家開講】鍵盤之王勇於跟蘋果說不 橫槓電單車闖出綠能移動一片天](https://www.mirrormedia.mg/story/20240807bus001)；定位：導言及鍵盤事業相關段落

## 判定

Overall `CANDIDATE_ACCEPTED`。

建議改寫：達方官網自述其為全球第一大筆電鍵盤製造商；官方未揭露排名依據或分母。

來源限制：
- 第一名的直接來源是達方官網自述，頁面沒有註明統計期間、比較對象、排名依據、分母或單位。
- 官網用語是「laptop keyboard manufacturer」；2022年公司簡介列出「Backlit Notebook Keyboard Module」，支持產品範圍涉及筆電鍵盤模組，但沒有把第一名排名明確限定在模組子類別。
- 2024年媒體所述「全球前三大」與第一名並不互斥，也不是獨立的第一名驗證。

已查核達方現行官網、公司法說會與公司簡介，並比對一篇2024年媒體報導；官方頁面直接支持全球第一的公司自述，但排名口徑仍未披露。
