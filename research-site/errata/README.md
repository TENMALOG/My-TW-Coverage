# 原專案勘誤表

對象：原專案 Timeverse/My-TW-Coverage（MIT 授權）的 `Pilot_Reports` 公司報告（1,733 家）。
依據：各公司 2025 年度年報（公開資訊觀測站）及逐句查核紀錄；每一筆勘誤都附可回查的依據。

| 表 | 內容 | 筆數 |
|---|---|---|
| `names.csv` | 公司名稱錯誤（亂碼、缺字、已更名未更新） | 14 |
| `classification.csv` | 產業分類與年報主要業務不符 | 137 |
| `claims.csv` | 高風險敘述（排名、市占、客戶、供應商、沿革等）逐句查核 | 1394 |

## 高風險敘述的查核結果（原句）

| 結果 | 句數 |
|---|---|
| 部分支持 | 1236 |
| 無法證實 | 114 |
| 原句通過 | 28 |
| 期間無法確定 | 9 |
| 補查後仍無法證實 | 5 |
| 不支持 | 2 |

「部分支持」表示原句有一部分與一手資料不符或無法證實（例如範圍、期間、排名說法），`更正後敘述` 欄是經一手資料證實的改寫；
空白表示沒有通過證實的更正句，該原句不應引用。

查核範圍說明：`claims.csv` 只涵蓋原報告中風險最高的敘述類型；其餘敘述未逐句比對，本專案改以年報重新整理每家公司的事實，不代表其餘原句皆正確。
