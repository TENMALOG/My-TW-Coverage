# 研究目錄與發布範圍清單（草案 v0）

建立日期：2026-10-11。評估基準日沿用凍結批次：**2026-10-08**。
本目錄只讀取既有報告與凍結交付，未修改原報告、作者 ledger 或任何 `audit-v5` 凍結檔案；輸入雜湊記錄於 `catalog-manifest.json`。
重建：`.venv/Scripts/python.exe -X utf8 research-site/scripts/build_catalog.py`

## 一、暫定研究題目與研究問題

**臺灣上市櫃企業的產業定位與供應鏈關係：以公開資料為基礎的可追溯研究**（名稱待示範章完成後收斂）

1. 各產業中的公司承擔哪些產品與技術角色？
2. 公開資料能支持哪些公司間關係（客戶、供應商、母子公司、歷史合作、技術採用）及其適用期間？
3. 各產業的公開資訊揭露完整度有何差異？哪些常見敘述（排名、市占、獨家）在查核後無法成立？
