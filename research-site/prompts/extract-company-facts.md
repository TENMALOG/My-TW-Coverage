# 任務：從年報切片抽取公司事實（company facts）

你會收到一份 `research-site/data/annual-slices/{ticker}.json`（一家公司一份年報的章節切片），請輸出一份 JSON，格式必須完全符合 `research-site/schemas/company-facts.schema.json`，**但不要輸出 `verification`**（那是驗證程式寫的）。

## 輸入欄位

`ticker`、`fy`、`filename`、`citation_url`、`text_sha256`、`text_path`、`legal_name`、`sections[]`。每個 section 有 `name`、`heading_found`、`start_page`、`end_page`、`text`（原文，內含 `[PDF PAGE n]` 頁碼標記）、`confidence`。

## 輸出

```json
{
  "ticker": "<同輸入>",
  "company": "<目錄中的公司簡稱；不知道就用 legal_name 去掉「股份有限公司」>",
  "legal_name": "<同輸入 legal_name>",
  "source": {"citation_url": "...", "fy": 0, "filename": "...", "text_sha256": "...", "text_path": "..."},
  "facts": [ ... ]
}
```

`source` 五個欄位從輸入原樣複製，不可更動。只輸出 JSON，不要加說明文字或 Markdown 圍欄。

## 每一則 fact

- `id`：`{ticker}-AR-01`、`-02` … 依序編號。
- `field`：只能是 `established, headquarters, history, business_scope, products, revenue_mix, sales_regions, export_share, market_position, raw_materials, major_suppliers, major_customers, capacity_or_production, employees, rd, group_structure, outlook`。
- `statement`：**一句繁體中文**，只寫引文明確說的事；不推論、不加形容、不補外部知識。數字保留年報的單位（仟元、%、人等），不要自行換算成億或百萬。
- `period`：事實適用的期間，如 `114年度（2025）`、`截至115年4月30日`。
- `page`：引文所在的 PDF 頁碼（`[PDF PAGE n]` 的 n，不是年報印刷頁碼）。引文跨頁時填起始頁。
- `excerpts`：一個或多個引文（每則至少 4 字）。
- `attribution`：`公司年報揭露`（預設）、`公司年報自述（未經獨立驗證的排名或評價）`、`公司年報引述第三方資料`。

## 引文規則（會被程式逐字比對，違反就判 FAIL）

1. 必須**逐字**取自切片 `text`，不可改寫、不可翻譯、不可省略號、不可補字、不可更正錯別字。
2. 取能支持 `statement` 的**最短連續片段**。空白與換行會被忽略比對，但字不能變。
3. 盡量不要跨越表格欄位；表格資料請每個數字所在的那一列（同一列的文字）單獨成一則引文，必要時用多則引文。
4. `statement` 裡出現的每一個數字，都必須原樣出現在某則引文裡（千分位逗號可不同；民國年與西元年可互換，如 114 年 = 2025 年）。
5. 引文必須出現在 `page` 指定的頁面（或延續到下一頁）。

## 內容規則

- 只使用切片文字；不要用你對這家公司的既有知識，也不要上網。
- 切片缺少的章節（沒有該 `name` 的 section）就**略過**，不要猜、不要補。
- 客戶或供應商若在年報中以代號出現（甲客戶、A公司、客戶 A），一律維持匿名，**不得**依代號或產業常識推測真實名稱；`statement` 要寫成「某客戶（代號）」並保留年報的代號。
- 年報中的自我描述或排名，例如「全球最大」「領導廠商」「市占率第一」，`attribution` 必須填 `公司年報自述（未經獨立驗證的排名或評價）`，且 `statement` 要寫成「公司於年報自述……」。引述第三方統計時填 `公司年報引述第三方資料` 並在 `statement` 標明來源。
- 評價性或成果性的說法，不論出現在哪一章（包括致股東報告書、競爭優勢），例如「成功轉型」「已具規模」「品質佳」「步入常軌」「已見成效」「世界知名大廠」，都屬公司自述：`attribution` 填 `公司年報自述（未經獨立驗證的排名或評價）`，`statement` 寫成「公司於年報自述……」。
- 列舉項目（原料、產品、客戶）要完整照列，或寫成「包括……等」；不要用「為」等字眼暗示清單已完整。
- 客戶或供應商的排名（第一大、主要）只有在年報表格明示名次或文字明說時才能寫；表格只列一家、其餘併入「其他」，不代表它是第一大。
- 同一份年報兩處數字不一致時（例如表格與內文），這則 fact 不要輸出。
- 金額一律寫出單位（例如「新台幣 1,234 仟元」），不可省略。
- 市占率、比例、市場規模一律寫出年報所說的範圍與分母（地區、產品市場、統計來源與年份），例如「占台灣地區上市櫃 PCB 廠合計營收 0.12%」；年報沒有交代範圍的比例不要輸出。
- 排名或市占若出自第三方（Gartner、Prismark、Omdia、TrendForce、工研院等），`attribution` 填 `公司年報引述第三方資料` 並在 `statement` 寫出來源，不可寫成公司自述。
- 年報寫的是目標、計畫或預期（「目標成為」「期望」「預計」）時，`statement` 必須保留這個語氣，不可寫成既成事實；描述過去狀態（「原先」「曾」）也要保留時態。
- 年度必須能從引文直接看出（引文含表頭的年度標示，或文字本身寫明年度）；不得用合計數或其他頁面推定年度，無法看出時整張表略過。
- 一則 fact 只講一件事；不要把多個數字或多個主題塞進同一句。
- 最多輸出 **25** 則 fact，優先順序：營業比重 → 產品／業務範圍 → 銷售地區 → 主要客戶與供應商 → 原料 → 市場地位 → 員工數 → 其他。
- 沒有足夠依據的欄位寧可不輸出，不要湊數。

## 範例（格式示意，內容為虛構）

```json
{
  "id": "1234-AR-03",
  "field": "revenue_mix",
  "statement": "114年度電子零件營業收入為1,234,567仟元，占營業比重85.5%。",
  "period": "114年度（2025）",
  "page": 84,
  "excerpts": ["電子零件 1,234,567 85.5"],
  "attribution": "公司年報揭露"
}
```
