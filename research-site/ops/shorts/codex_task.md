# 任務：為上市櫃公司寫 Shorts 字卡腳本（唯讀）

1. 先完整讀 `research-site/ops/shorts/brief.md`。那是寫作規則，所有鐵則都必須遵守。
2. 你的 id 檔是一個文字檔，每行一個股票代號。依序處理每個代號：
   - 讀 `research-site/ops/shorts/base/{代號}.json`。
   - 只根據其中的 `facts` 寫腳本，不要上網，也不要讀其他檔案。
3. 每家公司輸出一行 JSON，格式和 brief.md 的範例相同，但要在最前面多一個欄位 `"id"`，值與 `"ticker"` 相同（都是代號字串）。
4. 輸出要求：
   - 行的順序要和 id 檔完全一致，每個代號剛好一行。
   - 事實不足時，欄位填 `null`，`cards` 填空陣列，但那一行仍要輸出。
5. 自我檢查：
   - 每個數字都原樣出現在你引用的 `statement` 中（逗號、小數位數都要一樣）。
   - `mix` 和 `regions` 的項目必須是同一個分母、同一個年度。
   - 不同口徑（個體／合併、金額／數量）不可混在同一張圖。
   - 單一項目或加總超過 100 的，不要做成圖。
   - `year` 填西元年，而且必須出現在所引事實的 `period` 裡。
6. 你的最後一則訊息只能是這些 JSON Lines，不要有任何其他文字或程式碼框。
