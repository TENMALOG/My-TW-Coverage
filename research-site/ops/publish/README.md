# 臺灣上市櫃產業研究（年報查核版）

股.tw 研究室整理的臺灣上市櫃公司產業研究網站。涵蓋 98 個產業、1,733 家上市櫃公司，所有公司事實都取自各公司年報，並逐條查核後才收錄。

## 內容

- **產業章節**：每個產業的公司組成、產品與營收結構、上市櫃公司之間有年報依據的往來關係，以及附註腳的產業分析。
- **公司頁**：公司基本資料、名稱沿革、產品與營收結構、財務摘要、客戶與供應商、與其他上市櫃公司的往來關係；每一句都附年報頁碼與原始文件連結。
- **研究方法與證據附錄**：查核流程、裁定類別與研究限制。

## 查核方式

1. 從年報原文抽取事實，每條事實記錄頁碼。
2. 程式機械驗證：引文存在、頁碼正確、數字有出處、公司身分一致。
3. 兩輪獨立語意審查，再加一輪全面稽核；有疑義的事實依原頁修正，無法修正的不收錄。
4. 百分比一律寫明分母；表格列序不當成排名；年報匿名代號照代號呈現；不出現自然人姓名。
